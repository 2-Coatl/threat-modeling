# UI Use Case Catalog

Los casos de uso de la interfaz gráfica describen la interacción directa entre
los actores humanos y la experiencia web. Cada documento pone énfasis en las
acciones visibles para el usuario y en la respuesta observable de la UI,
manteniendo el vínculo con los casos de uso de API que soportan el flujo.
