# Agent Instructions for `docs/`

Estas pautas aplican a toda la documentación bajo `docs/`.

- Mantén los archivos en formato Markdown (`.md`) con encabezados jerárquicos
  claros y tablas alineadas mediante pipes para facilitar las revisiones.
- Asegúrate de que cualquier actualización conserve la coherencia entre
  secciones relacionadas (por ejemplo, índices, inventarios o tablas de
  mapeo). Si cambias un identificador, actualiza todos los enlaces que lo
  referencian.
- Prefiere descripciones centradas en la experiencia del usuario o lector;
  los detalles técnicos profundos deben residir en guías específicas bajo
  `api/` o `infrastructure/`.
- Cuando introduzcas nuevas convenciones o plantillas, documenta el objetivo y
  enlaza al recurso correspondiente para mantener la trazabilidad.
