# Instrucciones para `docs/bussines-rules/`

- Mantén la visión general y el catálogo sincronizados: si agregas o renombras
  secciones en uno, actualiza los enlaces cruzados y tablas de contenidos en el
  otro para que los lectores puedan navegar entre ambos documentos.
- Usa rutas relativas desde este directorio (prefijo `./`) al enlazar entre
  archivos y verifica que los enlaces externos (p. ej. a `docs/standards/` o
  `docs/use-cases/`) permanezcan válidos después de mover contenido.
