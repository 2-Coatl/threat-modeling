# Generated Outputs

This directory contains auto-generated threat model outputs.

## Structure
- `diagrams/` - PNG images (DFD and Sequence diagrams)
- `reports/` - HTML reports

## Note
Do not manually edit files here. They are regenerated each time you run `./bin/generate`.

## Viewing

```bash
# List diagrams
ls diagrams/

# List reports
ls reports/

# Open report in browser (if available)
firefox reports/auth_model_report.html
```
